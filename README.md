# Rewin Admin Panel V2

## Project Overview
This is the new, redesigned version of the Rewin Admin Panel built from the ground up with modern best practices and a clean architecture.

## Design System
All design specifications are documented in `AdminPanelTheme.md`. This ensures consistent styling across all components and pages.

## Key Improvements Over V1
- ✅ Clean, modular architecture
- ✅ Comprehensive theme documentation
- ✅ Modern React patterns
- ✅ Better error handling
- ✅ Improved performance
- ✅ Enhanced accessibility
- ✅ Consistent design system

## Technology Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Backend**: Node.js + Express + TypeScript
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **Styling**: CSS-in-JS (following theme specification)
- **Icons**: Lucide React
- **Build Tool**: Vite (modern alternative to Create React App)

## Getting Started
```bash
# Navigate to the new admin panel
cd rewin-admin-panel-v2

# Install dependencies (when ready)
npm install

# Start development server
npm run dev
```

## Design Principles
1. **Consistency**: Follow the theme specification religiously
2. **Performance**: Optimize for speed and responsiveness
3. **Accessibility**: Ensure WCAG compliance
4. **Maintainability**: Write clean, documented code
